## 2. Appプライバシーレポート：約1日の観測報告あり

2026-10-20 15:17に送り先をすべてオフにして文字起こしを実施。レポートをオンにしたのは15:20であり、観測開始は15:20です。翌21日、利用者から約1日後にIndex Relayの記録がなかったとの報告を受けました。終了時刻の厳密な記録・レポート書き出し・パケット記録は未取得です。15:17の操作は有効化前なので観測結果に含めません。

送り先をオフにするだけでは、登録済みURLSessionタスクや設定画面での登録先確認まで停止しない。既存の送信一覧とOS登録済みタスクの状態を確認し、残存要求がある期間は区別する。モデルの初回準備／更新に伴う通信がOS側にどう帰属するかも区別し、送り先をオフにしたまま登録確認などのAPI操作を行わない。

設定 → プライバシーとセキュリティ → Appプライバシーレポートを有効にし、観測開始時刻と終了時刻を記録する。通常の録音・文字起こしを1日程度使い、Index Relayの接続先・時刻を観測前の記録と比較する。レポートは過去7日間を表示するため、試験前の通信を混同しない。有効化前のデータは記録されない。レポートをオフにすると他アプリ分も含めて消去されるので、既存記録を消すことは必須にしない。[Apple公式](https://support.apple.com/102188)。

合格条件は「この観測期間・操作条件で説明できない接続先が見つからないこと」。一覧が空でも無通信の証明とは扱わない。不明な接続があれば、時刻・操作・送り先API・モデル準備などを照合し、必要ならパケット観測へ進む。静的検査もこの実観測も、すべての通信方式の不存在を証明しない。
